# Builds

**Builds** in Dark Souls 3 are user created combinations of [Stats](/Stats), [Weapons](/Weapons), [Armor](/Armor), etc. that work best to achieve a certain goal or set of goals. You can use the links below to find different approaches and ideas, or find interesting combinations to spice up your playthroughs.
